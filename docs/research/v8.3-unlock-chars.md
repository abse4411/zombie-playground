# 调研 · 解锁角色设计（v8.3）——已读 INDEX 全部，本篇为干员解锁增量

来源：Hero shooter 设计(独特被动=角色身份, 定制最小化保平衡)、R6S/Delta Force 干员定位(侦查/爆破/支援)、
CODM Demo Expert(爆炸伤害+40%类perk)。

## 设计原则
- 解锁角色的被动要**改变玩法**而非纯数值(主动技能本作暂无, 用强被动+武器配置差异)
- 解锁条件=成就链（给成就系统提供长期目标）

## 新干员2名（与现有4人互补）
### ghost 「幽灵」女 · 狙击手（成就解锁: head300 爆头艺术家）
- hp 80(脆) speed 1.08 reload 0.85(快) dmg 1.0 medkits 2
- 特性: **开局免费获得 AWM**(起始武器配置 weapons 配置) + 狙击开镜移速惩罚减半(稳)
- 定位: 远程清场流, 成就链呼应爆头玩法
### demo 「雷公」男 · 爆破专家（成就解锁: fragkill20 爆破专家）
- hp 110 speed 0.98 reload 1.1 dmg 1.0 medkits 2
- 特性: **爆炸伤害×1.5**(手雷/榴弹/爆炸桶/火箭) + 投掷物携带上限+2 + 开局手雷满
- 定位: 爆破流, 成就链呼应手雷玩法

## 实现落点
- CHARACTERS 加2项(带 unlockBy 成就id + passive 字段)
- 菜单角色卡显示 锁🔒+解锁条件; 游戏内 _begin 应用 passive:
  - ghost: charStats 无需改, weapons起始配置含awm, scopePenaltyHalf flag
  - demo: explodeMult 1.5 (explodeGrenade/takeDamage 爆炸路径乘算) + throwMaxBonus 2
- 角色选择UI: locked 状态遮罩 + 解锁提示
