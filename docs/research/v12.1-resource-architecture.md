# 调研 · 资源文件化 + 懒加载 + 内存泄露防治（v12.1~v12.4）

来源：Three.js GPU 资源不自动回收（geometry/texture/material 须显式 dispose）、dispose 遍历助手、
纹理图集省显言、POT 纹理尺寸、对象池/共享材质模式、renderer.info + performance.memory 泄露监控。

## 现状盘点（本代码库已有的基建）
| 系统 | 现状 | 结论 |
|---|---|---|
| ENGINE.clearMap | 深度释放：geometry.dispose + 非缓存材质 + __tracked 纹理克隆 | ✅ 场地级释放已有 |
| ZOMBIE_POOL | 每类上限10个模型池，溢出才 dispose | ✅ 已有，补：退局全清 |
| PARTICLES/BLOODPOOLS/DMGNUM/HPBARS | 池化 + 共享几何/材质 + 上限 | ✅ 已有 |

## 外置方案（数据/代码边界）
| 文件 | 构成 | 处理 |
|---|---|---|
| weapons.js | 纯数据 | → assets/data/weapons.json（weapons+throwables） |
| zombies.js | 纯数据 | → assets/data/zombies.json |
| characters.js | 数据+1辅助函数 | → characters.json，辅助函数留代码 |
| story.js | 纯数据（483行） | → missions/index.json（元数据）+ missions/m*.json（波次/对话，**开局才加载**） |
| maps.js | STRUCTS构建器(代码)+8图纯数据 | → maps/index.json（菜单元数据）+ maps/<id>.json（**选图/开局才加载**）；STRUCTS+drawMapPreview 留代码 |
| perks.js | 数据+valName函数 | valName → 模板字符串 `{v}`/`{v%}`，加载后回挂格式化函数 |
| achievements.js | 数据+goal函数 | goal → {stat,target} 数据（Proxy 提取），加载后回挂求值器 |
| gameConfig.js | 平衡调参常量 | 留代码（属调参不属于内容资源） |

## 懒加载时机
- 启动异步加载：weapons/zombies/perks/achievements/characters/missions索引/maps索引（带进度条）
- 进地图时：maps/<id>.json（startHunt/startMission）
- 开任务时：missions/<id>.json（对话+波次）
- 打开猎场选择页：全部 maps/<id>.json（画缩略图需要 props）

## 泄露防治补强
- 退出对局：ZOMBIE_POOL 全类型 dispose 清空（GPU 释放）+ _cleanupWorld 已有链条保持
- RES JSON 缓存 LRU 上限（非核心组可驱逐，核心组常驻）
- FPS HUD 增加几何/纹理/JS堆 三项监控（performance.memory 仅 Chrome）
- 热路径零分配：_fire 的 origin/fwd/right/up 改模块级临时向量（每次开火省4个Vector3）

## 陷阱备忘
- MISSIONS 索引必须含 brief/objective/map（菜单卡片用）；对话波次在详情
- ACHV visit_all 用 Object.keys(MAPS).length → MAPS 启动即有全 8 条元数据，不受懒加载影响
- startMission/startHunt 变 async：防重入标志 + loading 遮罩；NET.startNetGame 同路径无需改
- 结构体构建器 STRUCTS 内有 ENGINE.anims 闭包 —— 属代码，不外置
