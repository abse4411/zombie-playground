## 3A主菜单配方 → 本项目落地
1. **实时3D背景场景**：主角(选中角色持枪姿)+2只丧尸对峙+地面雾气，缓慢相机漂移(±0.2m 呼吸感)
2. **角色侧立构图**：模型放右侧 2/3 处，左侧留菜单栏（DOOM 式非对称）
3. **轮廓光**：冷蓝 rim light + 暖 key light 打模型
4. **排版**：大标题+细字距副标+左侧竖排菜单按钮(hover 变红+左移)
5. **底部信息条**：版本+成就进度+存档干员（不喧宾夺主）
6. **菜单浮层半透明暗化**背景场景，保证可读性

## 实现（纯前端复用现有渲染器）
- MENU3D 独立场景：buildPlayerBody(选中角色)+持枪臂+AWM + walker/brute 对峙 + 地面圆台
- 相机漂移：camera.position.x = sin(t*0.1)*0.3
- menu-btn hover CSS 已有 translateX——加强：左侧红色指示条+背景亮化
- screen-menu 改 flex 布局：左列菜单 右侧 canvas(全屏背景 z-index -1)
