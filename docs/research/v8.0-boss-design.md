# 调研 · 终局Boss设计（v8.0）——已读 INDEX 全部，本篇为 Boss 机制语言增量

来源：GameDeveloper Boss结构(攻击模式按"上下文+阶段"部署)、TVTropes三段式终Boss惯例、
Telegraph设计(前摇可读+**攻击后惩罚窗口**)、UnrealSP Boss竞技场机制(阶段改变时Boss转向远程)。

## 设计原则 → 母体泵守护者（m10 终章Boss）
1. **三阶段**：100~60%常规定期攻击 / 60~30%解锁组合技 / <30%狂暴加速+全场压力
2. **前摇明确**：每个大招有独立音效+横幅提示+0.6~1.2s蓄力，给玩家可反应窗口
3. **攻击后惩罚窗**：大技能后有2s硬直，玩家输出窗口
4. **阶段转换**：转段时全场尸潮退散+Boss短暂无敌怒吼（换血演出）
5. **火焰弱点**：燃烧DoT对其伤害×1.5（呼应v7.9火焰喷射器——武器生态闭环）

## 母体泵守护者 pumpWarden 数值案
- base: brute, scale 2.5（最大Boss）, hp 4800, speed 2.0, dmg 50, reward 6000
- attacks:
  - slamEvery 7（跺地AOE 50dmg/7m）—— 常规
  - tentacleEvery 6（**触须横扫**：12m直线扇形40dmg+击飞）—— 前摇1s音效
  - spikeEvery 9（**地刺矩阵**：以玩家当前位置为中心3×3地刺阵, 每刺18dmg, 1.2s前摇红圈提示）
  - summonEvery 14（召唤舔食者×2 —— 专属小弟）
  - frenzy(phase2): 全技能间隔×0.65 + spikeN 3×3→4×4

## 实现落点
- GAMECONFIG.bosses.pumpWarden + zombie.js Boss块新增 tentacleEvery/spikeEvery 两个攻击组
- spike 地刺：PARTICLES.dust + ENGINE临时AABB伤害圈（视觉=地面红圈sprite×N）
- 火焰易伤：zombie.takeDamage 内 bossCfg.weakFire 时 burnDps×1.5
