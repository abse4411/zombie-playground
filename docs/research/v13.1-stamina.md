# 调研 · 射击游戏体力系统设计（v13.1~v13.3）

来源：Hedberg Games《Stamina in Action Games》（回复速率=节奏主杠杆）、Insurgency Wiki（硬体力拟真派）、
CoD Unlimited Sprint Perk（体力作为成长奖励）、Dying Light 隐形冲刺体力+可见战斗体力、
Titanfall/Doom 无体力流派（移动即核心手感，摩擦杀死流畅）、ResetEra 社区争论（体力不应卡基础移动）。

## 设计光谱与定位
| 流派 | 代表 | 适用 |
|---|---|---|
| 无限冲刺 | Titanfall/Doom/Halo5 | 移动即核心玩法 |
| 体力=成长奖励 | CoD 冲刺Perk、DL敏捷技能 | **本作定位：商城升级线** |
| 硬体力 | Insurgency/生存拟真 | 战术 pacing |
| 隐形冲刺体力 | Dying Light1 | 后果存在但不唠叨 |

**本作折中**：走路永久免费（基础移动不被卡）→ 冲刺/战术踢/闪避消耗 → 体力条+疲劳锁定增加战术节奏
→ 商城两条升级线+角色差异化提供 build 深度。

## 关键数值设计（Hedberg：回复速率是第一平衡杠杆）
- 冲刺持续 ≈ 7s 满体力（drain 14/s @ max100）——够穿越一张图的一半，不够无限放风筝
- **双速回复**：站立 38/s（≈2.6s 回满，鼓励停下观察=风险换资源）、走路 16/s（≈6s，移动中缓慢回）、冲刺中不回复
- **疲劳锁定**：体力归零 → exhausted，须回到 30% 才能再冲刺（防 0/0/0 抖动刷跑；给 HUD 红色警示）
- 瞬耗动作：战术踢 18、闪避冲刺 25 —— 关键保命/控制动作有明确体力价签
- UI：体力条 <30% 转橙、exhausted 红闪；归零瞬间 toast 提醒
