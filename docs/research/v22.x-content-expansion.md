## 工程教训
1. 顶层 class 的 TDZ：原型赋值若写在 class 声明前，整个脚本执行中断，类永久 TDZ（typeof 都抛错）
2. IAB 缓存键偶发忽略 query——版本号必须 bump 才能保证新 JS 生效
3. 测试丧尸 spawnOne 后默认 rise 态（起身无敌）：接触类测试必须先置 state='chase'
