# 调研 · 武器模型精致化设计语言（v7.2）

来源：3D武器制作管线(nastyrodent/80.lv/3d-ace)、枪械剪影辨识(GunGuesser)、ArtStation游戏道具剪影理论、H&K官网/Wikipedia枪械解剖。

## 核心原则：剪影辨识度（Silhouette First）
游戏武器第一识别要素是剪影——每把枪必须有 1-2 个"标志性剪影件"，让玩家不看名字就认出枪。

## 通用部件库（部件化建模 checklist）
机匣receiver / 枪管barrel / 护木handguard / 弹匣magazine(弯|直|鼓) / 瞄具sight(机瞄|红点|高倍镜) /
枪托stock(固定|伸缩|骨架|拇指孔) / 握把grip / 消音器suppressor / 导轨rail / 前握把foregrip / 栓动柄bolt / 拉机柄charging handle

## 各枪标志性剪影件（本项目现有17把）
- AK-47：**弯"香蕉"弹匣** + 木托木护木 + 导气管 + 斜切枪口
- M4A1：**伸缩托** + 平顶导轨/提把 + 直弹匣 + A2准星座
- MP5：**直弹匣略前倾** + 护圈式准星环 + 紧凑滚柱机匣 + 细护木
- AWM：**拇指孔枪托** + 大倍率瞄具 + 厚重枪管 + 栓动拉柄 + 两脚架
- SCAR-H：上机匣一体化长导轨 + 侧折托 + 大口径粗弹匣
- P90：**无托 bullpup 一体化壳** + 顶部供弹横置弹匣 + 集成握把
- SPAS-12：**泵动+半自动双护木套筒** + 粗枪管 + 钩形托
- M249：**弹鼓/弹箱** + 两脚架 + 提把 + 粗枪管导气管
- Deagle/R8/G18/P92（手枪）：套筒slide+底把frame两层、扳机护圈、短弹匣插底把
- 军刀/斧/电锯（近战）：刃部高光材质区分 + 柄部缠绕细节 + 锯齿/斧刃剪影
- M79：短粗单管 + 木托 + 大口径喇叭口
- 双管截短霰弹：双管并列 + 极短全长

## 实现约定（本项目）
- 统一 buildGunModel(def) 部件化建模器：材质复用 body/dark/metal/wood 四色 + ART.outline 描边
- 每把枪 8~14 个 box/cylinder 部件；弹匣弯曲用 2 段折角 box 近似
- 模型原点在握把处、单位朝 -Z（与 viewmodel 挂载约定一致），商城预览可直接复用
