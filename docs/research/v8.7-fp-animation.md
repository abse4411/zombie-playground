# 调研 · 第一人称动作系统（v8.7）——已读 INDEX 全部，本篇为FP动画语言增量

来源：GDC Mirror's Edge(双身体架构:FP代理+全身real rig)、Zeno Clash GDC(FP近战三要素:
**双身体/从FP视角做动画/预备动作anticipation**)、Dying Light GDC2018(跑酷:检测几何→按速度选动画)、
MoCap Online(持续状态=相机动画,瞬时事件=屏幕效果)、12原则FPS适配(预备/跟随/夸张)。

## 核心原则 → 本项目落地
1. **预备动作**：踢腿先收腿再弹出(anticipation 0.08s) → 踢击可读性
2. **跟随/过冲**：踢出后过冲回弹(follow-through)，近战挥完手臂过摆
3. **双身体**：踢/翻滚/投掷在第三人称身体(playerBody)播放对应姿态——低头看得到自己的腿在做动作
4. **相机语言**：冲刺FOV+头部摆动频率变化；踢腿相机轻微下沉后仰；翻滚相机滚转
5. **屏幕效果**：dash速度线(sprite/vignette)、踢中hitstop强化

## 动作清单（现状→目标）
| 动作 | 现状 | v8.7 目标 |
|---|---|---|
| 脚踢 | 视图模型仅位移ox/oy 0.1,**无腿部** | playerBody 右腿弹踢(rotation.x -1.4→0.4过冲)+视图模型下沉后仰加强 |
| 闪避冲刺 | 仅位移,无动作 | 身体侧倾(rotation.z 0.3)+蹲低(scale y 0.85)+FOV punch+屏幕速度线 |
| 投掷 | 枪口火光代替 | 视图模型抬臂过肩投掷姿态(0.5s)+playerBody 右臂前挥 |
| 近战 | 挥刀弧光+视图模型rz摆 | 增强:-playerBody右臂横挥+相机横移跟随+击中顿帧已有 |
| 冲刺 | FOV微变 | bob频率×1.4+FOV+8平滑+身体前倾5° |
| 换弹 | 已有大幅翻枪 | 保持 |
| 跳跃/落地 | 落地重脚步声 | 落地相机下沉回弹(landing dip)+起跳微仰 |

## 实现
- playerBody 加 actT/action 状态机(由 game 驱动): kick/dash/throw/swing 各自姿态函数
- weaponSystem._kick 触发 game.playerBody act('kick'); _throw 触发 act('throw'); swing 触发 act('swing')
- _updateViewmodel 加投掷臂摆(throwAnimT) 与踢腿下沉(kick已有,加强幅度)
- 相机: game 相机段读取 player.actT 应用 dip/roll/lean
