# 调研 · 小Boss机制 + 人类敌人AI（v15.1~v15.4）

> 来源：L4D/WWZ Wiki、Destiny encounter design、Borderlands crit spot、
> TLoU 人类AI（Game AI Pro 2 Ch.34）、Days Gone Marauders、GDC Boss Battle Design Fundamentals。

## 一、小Boss 登场宣告（L4D Tank / WWZ 三件套）

- **登场三件套**：专属音效（低吼/号角渐入）+ 屏幕横幅（"重型感染者出现"）+ 短暂慢镜/震屏。
  音乐本身就是预警系统——给玩家 2~3 秒反应时间。
- WWZ 特感靠**外观标记**识别（Bull 正面装甲 / Gasbag 黄色气罐 / Screamer 召唤），
  弱点部位单独 hitbox + 发光材质提示。
- 可落地：`spawnMiniboss()` 内 HUD.banner + AUDIO.hordeHorn + ENGINE.shake + game.slowmo(0.55)；
  空闲时占用 Boss 血条（幕末Boss优先）。

## 二、阶段转换与弱点（Destiny / Borderlands）

- Destiny：Boss 战 = "机制阶段 → 输出窗口"交替；**50% 血量阈值**触发阶段转换是标准旋钮。
- Borderlands **crit spot**：弱点常在非常规位置（背部/发光囊/外露核心），迫使绕位；
  弱点伤害给额外倍率并弹暴击数字。
- 狂暴阶段**免疫眩晕**，防止无限控制链。
- 可落地：`_miniPh2` 半血触发（提速 + 免硬直 / 铁壁弃盾反转弱点）；`weakHead` 爆头额外倍率；
  狂暴期红色雾气粒子标识。

## 三、Mini-Boss vs Boss 的边界

- 共识定位：新机制的**教学性首个挑战**——比普通怪强、比关底Boss弱。
- **血量取普通怪 8~15 倍**支撑 20~40 秒战斗，不做数值膨胀；专属技 1~2 个；
  好的 Boss 战靠**可读的 attack telegraph**（前摇动作/蓄力光效/红圈预告）而非伤害堆叠。
- 反"血包怪"三招：给弱点、给连续命中递增、给明确输出窗口（换弹/技能后摇）。
- 可落地：三小Boss 各 1~2 专属技（军阀手雷+召唤 / 铁壁冲锋+跺地 / 女妖声波+召唤），
  前摇全部可读（站定蓄力/横幅提示/红圈粒子）。

## 四、人类敌人 AI（TLoU / Days Gone Marauders）

- 三支柱：**掩体、潜行、侧翼包抄**；小队 3~6 人；Assaulter 用压制火力把玩家钉死，同伙包抄。
- 行为循环：追近 → 掩体 → 探头点射 2~3 发 → 缩回换弹（**换弹=击杀窗口**）→ 侧移换位。
- 共通弱点：**爆头即死/高倍**；对枪手造成任意伤害可打断瞄准（压制交互）。
- 扔雷有落地提示音；被瞄准时人类会规避。
- 可落地（v15.1 gun AI 状态机）：
  - 距离带 `keepMin~keepMax`：过远接近（>26m 小跑）/ 过近后撤 / 带内横移走位；
  - 开火循环：`aimTime` 瞄准前摇（telegraph，狙击手亮激光）→ `burst` 连点（burstGap 间隔）
    → `cooldown` 冷却 → 弹匣打空 `reload` 秒换弹（期间后撤+不可开火）；
  - 命中率 = acc × 距离衰减 × 玩家移动惩罚(0.62)/冲刺惩罚(0.4) × 闪避帧(0.12)；
  - `takeDamage` 打断瞄准（+0.5s）；玩家 ADS 瞄枪手时枪手横移加速 + 前摇×1.4；
  - 曳光（TRACERS）+ 枪口火花 + 距离衰减枪声（AUDIO.shot 带 dist）。

## 五、奖励设计（Borderlands 模式）

- 小Boss 保底掉落：大量资金 + **必掉补给箱×2** + 击杀横播（正反馈强化）。
- 人类小队掉资金与弹药（走通用 spawnLoot）。
- 不计入幕末Boss成就（`!z._isMini` 门），避免成就膨胀。
