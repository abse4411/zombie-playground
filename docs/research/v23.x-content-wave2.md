## 工程备忘
1. spawnOne 出生的丧尸默认 rise 态（起身无敌）：接触类机制测试必须先置 state='chase'
2. 新道具需同步三处：GAMECONFIG.items、ITEM_KINDS（道具栏）、LOOT_ITEM_KINDS（掉落自动拾取）
3. 新投掷物八件套：PROJ_CFG / THROWABLES / THROW_KINDS / update 行为 / autoCollects / collect case / LOOT_MODELS / LOOT_LABELS
