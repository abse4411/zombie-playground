# 丧尸游乐场 · Zombie Playground

一款纯前端、零外部资源依赖的 **3D 第一人称丧尸射击游戏**（Three.js + WebAudio）。
**无主之地式美漫渲染**（Toon 分档着色 + 粗黑描边 + 程序化纹理）、**电脑/手机/平板全端支持**、
**新手教学训练营**、剧情遭遇战（5章）与无尽狩猎两大模式、9 种感染体、14 件武器、5 张地图、
完整商城强化、导演系统、成就系统、动态天气、动态音乐与打击感设计。

> 电脑：双击 `启动游戏.bat`（或 `index.html`）。手机/平板：任意静态服务器（`python -m http.server 8080`）后用浏览器访问，自动进入触屏模式。

## 一、游戏模式

### 🎓 新手教学 · 训练营
11 步分步教学：移动 → 疾跑跳跃 → 射击 → 爆头 → 换弹 → 近战 → 手雷 → **闪避冲刺** → **战术脚踢** → 商店购物 → 毕业考核。
训练假人站桩陪练（自动补充），左侧目标清单实时指引，触屏设备自动切换触屏文案；进度存档，可随时跳过。

### 🎯 狩猎模式（无尽求生）
- 波次预算逐波上涨，同屏上限最多 36 只（随画质/设备自适应），三档难度。
- 每波清空：资金奖励 + 15 秒休整 + **慢镜清算演出**。
- **导演系统**（World War Z 式）：随机触发 **尸潮突袭**（成群奔跑者）/ **空投资金** / **精英提前登场**。
- **连杀系统**：连续击杀播报，每 5 连杀发奖金；受击即断。

### 📻 遭遇战模式（剧情战役）
5 章逐章解锁（进度自动保存），固定时长坚守：**时间结束**或**全波次清零**即胜利。每章含开场简报/中段插入/结局对话。

| 章节 | 地图 | 时长 | 核心演出 |
|---|---|---|---|
| 第一章 · 地下信号 | 滨港地铁站 | 4:00 | 潜行者登场，掩护老周修复中继器 |
| 第二章 · 乐园惊魂 | 荒废游乐园 | 5:00 | 小丑感染体（地图限定），营救林晚 |
| 第三章 · 血样 | 疫病医院 | 6:00 | 尖啸者成群，取样并发现清剿队残骸 |
| 第四章 · 撤离点 | 废弃街区 | 7:00 | 装甲暴兵登场，轰炸倒计时下的撤离 |
| 终章 · 黎明行动 | 军事基地 | 8:00 | 三波“守门人·暴君”，炸毁病毒源头 |

**剧情梗概**：2026 年军方“游乐园”实验设施泄漏“赤潮病毒”，雇佣兵“渡鸦”受“黎明会”委托：修复通讯、营救病毒学家林晚、夺取样本、轰炸前撤离、最终摧毁源头广播解药。

## 四、商城与强化

资金：击杀赏金 + 爆头加成 + 连杀奖金 + 波次奖励 + 空投。补给区光环内 `E`/`B`（或触屏 🛒），狩猎休整期全场可购。

## 五、打击感与音效（3A 向打磨）

- **顿帧 Hitstop**：爆头击杀 75ms 全局冻结，普通击杀 45ms；波次清空 **慢镜清算**。
- **击退冲量**：霰弹/近战/脚踢/爆炸都会把丧尸轰退；**F 战术脚踢**（Dying Light 式）：1.1 秒大硬直+9 冲量。
- **C 闪避冲刺**：0.3 秒无敌帧穿过尸群。
- **反馈**：受击方向红箭头、近距离击杀屏幕血溅、连杀播报、枪口动态光、命中数字弹跳、低血量心跳。
- **音效全合成**：按武器调音的枪声、脚步（走/跑两种）、火焰环境声、随尸群数量增强的**紧张度分层低鸣**、丧尸低吼距离衰减、尖啸、爆炸低频、购买/连杀/尸潮号角/毕业旋律。

## 六、美术（无主之地式美漫画风）

- **Toon 分档着色**（3 档明暗）+ **反向壳粗黑描边**（丧尸/枪模/建筑/地标全描边）。
- **程序化纹理**：沥青地面（噪点+裂缝+补丁）、建筑窗格（亮灯随机）、马戏团条纹（帐篷/木马顶棚）、金属板（铆钉+锈迹）。
- **天空穹顶**：每图垂直渐变 + 星空；霓虹灯色 + 体积雾氛围。
- 丧尸细节：下颚血口、破布血污、装甲头盔/挂载包、小丑双角、暴君肩甲、发光眼睛（红/黄）。

## 七、性能（不卡顿保障）

- **自适应画质**：帧率 EMA 监控，低于 44FPS 自动降档（分辨率 2.0→1.4→1.0、关闭描边、粒子缩减、刷怪上限减半），高于 57FPS 自动回升；设置中可手动锁定 高/中/低/自动。
- **材质缓存**：同色材质全局共享，材质状态切换大幅减少；几何体复用。
- **远处 LOD**：超过画质对应距离（48/34/24m）的丧尸跳过骨骼动画。
- **触屏设备**：刷怪上限额外 ×0.72、默认中档画质。
- 实测：桌面中端显卡 75FPS（全描边+高分屏），场景 36 丧尸无掉帧。

## 八、跨端支持（电脑 / 手机 / 平板）

- **桌面**：键鼠 + 指针锁定。
- **触屏**：自动检测——左侧**浮动虚拟摇杆**（按住处生成）、右半屏滑动视角、实体按键（🔥开火 / 🎯瞄准切换 / ↻装填 / ⤒跳 / ⚡闪避 / 👟脚踢 / 💣🧪投掷 / 1·2·3切枪 / 🛒商店 / ⏸暂停）；HUD 自动重排，禁用双击缩放。
- 页面自动暂停：切后台/失焦即暂停（音频同步挂起）。

- **Back 4 Blood**（本轮补充）：卡组建构筑的得与失 → 保留多级 Perk、以导演事件提供随机性。

## 十二、常见问题

- **双击 index.html 无法进入？** 用 `启动游戏.bat`，或本地服务器 `python -m http.server 8080`。
- **没有声音？** 首次点击页面后浏览器才启用音频。
- **手机上卡？** 设置→画质→自动（默认），帧率低会自动降档；也可以手动选“低”。
- **进度丢失？** 清理浏览器数据会重置存档（localStorage）。
