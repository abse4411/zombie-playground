# 调研 · 现代射击游戏 HUD 设计语言（v21.4）

来源：UX Collective diegesis 理论、Game Developer 沉浸感设计、Apex/CoD HUD 拆解（社区分析）。

## 设计原则（采纳）
1. **角落放玩家状态，边缘放世界状态，中央保持干净**（准星区域零遮挡）
2. **情境化显色**：低弹药橙/红脉冲、血条渐变+发光、爆头金/击杀红边条
3. **Apex 式分层条**：护甲条叠在血条上方（颜色区分层级）
4. **非拟真+风格化皮肤**：不做 Dead Space 全拟真（可读性/无障碍代价大），
   用半透明暗面板 + backdrop blur + 切角（clip-path 平行四边形）统一风格
5. **大号弹药数字**（52px/900字重）右下，武器名大写字距展开

## 落地（纯 CSS 覆写层，DOM/JS 零改动）
- #hud-bl / #hud-br：切角暗面板 + 金色边线 + blur
- .bar：斜切条形，HP 绿渐变/护甲蓝渐变/体力金细条/经验紫
- #ammo-mag 52px 大数字 + low/empty 脉冲动画
- #slots-row 药丸槽位（active 金色高亮）
- #killfeed 右中暗 chips（爆头金边/大招红边）
- #money-row 金块标签 + 药丸化医疗包/背包提示
