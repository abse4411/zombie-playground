# 调研 · 感染体造型精致化设计语言（v7.3）
# （已读 INDEX + v7.2 武器调研，本篇为丧尸主题增量，不重复武器内容）

来源：生化危机怪物设计(Licker/Tyrant/Regenerator/ Cerberus/Plant 43)、生存类游戏感染体造型综述、剪影理论(同v7.2不重复)。

## 造型语言要点（生化危机系）
- **Licker 舔食者**：无皮暴露肌肉（红/粉色肌理）、长舌、脑组织外露、爬行巨爪 —— "暴露内部"是恐惧来源
- **Tyrant 暴君**：巨大人形 + 夸张解剖（外露心脏/利爪右臂）—— 剪影=巨肩+不对称巨肢
- **Regenerator 再生者**：臃肿肿胀躯体 + 呼吸起伏 + 凹陷孔洞 —— "肿胀感"用大比例腹部
- **Cerberus 地狱犬**：腐坏犬类+外露肋骨
- 通用：**不对称变异**（一侧变异另一侧正常）最有恐怖感；暴露肋骨/脊椎刺 = 低成本高辨识件

## 本项目14型专属特征件规划（方块美学框架内）
- walker 游荡者：外露肋骨条×3、歪斜头（rotation.z 常驻0.18）、拖拽臂（一臂更长）
- runner 奔跑者：前倾躯干(rotation.x 0.18)、瘦削四肢（细20%）、奔跑张口
- stalker 潜行者：贴地爬行(已有)、脊刺×4、长前臂
- spitter 吐酸者：喉囊（喉部球体）、嘴角黏液丝、腹部酸斑
- bloater 膨胀者：巨腹（躯干前叠加鼓胀块）、气孔斑×4、表皮绷紧色
- screamer 尖啸者：巨颅(已有headBig)+深张口+喉管外露
- armored 装甲暴兵：护膝×2、肩甲加宽、面罩板、弹挂袋×3
- jester 小丑：彩条补丁×4、歪斜礼帽（帽+檐）、裂口笑容
- charger 冲锋者：单侧巨肩+粗臂（不对称变异）、背部肌束条
- toxic 腐蚀射手：背部囊袋×2、滴落酸迹、暗绿表皮
- radiant 辐射变种：体表荧光晶体×3（emissive）、发光血管条
- phantom 幽影：残破披风片×2、细长指爪
- hound 地狱犬：外露肋骨、脊刺×3、断尾
- boar 獠王：弯曲獠牙×2、背鬃锯齿×4、厚皮褶皱条
- brute 暴君：外露心脏（胸口红块）、不对称巨右臂、装甲残片

## 实现约定
- 保持在方块美学+描边框架内：每型 2~4 个特征件（box/sphere/emissive块）
- buildZombieModel 内按 cfg.id switch 追加"专属特征段"；配色延续 cfg 皮肤/布料
- 特征件纳入肢解系统可见性管理（可见性由对象池统一恢复，无需额外处理）
