# 调研 · 背包架构设计（v9.2）——已读 INDEX 全部，本篇为背包/仓库系统增量

来源：Tarkov stash/loadout 分离(仓库可扩容10x28→10x68, 装备栏出装带风险)、RE4 attaché case(格子容量+商城扩容
+箱子加成perk)、Borderlands 六级稀有度白绿蓝紫橙、Loadout Locker 概念(一键从仓库配置装备)。

## 核心架构（本项目落地：装备栏/背包双区制）
- **装备栏 Loadout**（立即生效，按1/2/3直切）：
  primary×2 + secondary×2 + melee×2 + throwable(计数) —— 每槽2格（原 rack 是无限列表，用户痛点=按1循环麻烦）
- **背包 Storage**（容量制，需打开配置）：买过/掉落的武器与物品暂存于此
  - 默认容量 6 格，商城可升级 6→9→12（RE4式 attaché case 扩容）
  - 武器/物品同格混装；满时拾取武器类战利品自动折现（RE4式拒收→折钱）
- **流转规则**：
  - 商城买新武器 → 直接装备到对应装备槽；**若该槽2格全满 → 旧武器(手中那把)自动进背包**
  - 背包满 → 买武器时提示"背包已满"但仍可换装（装备槽是硬位）
  - 掉落稀有武器 → 有空位入背包/直接提示换上；满则折现+提示
  - 背包内点击武器 → 与当前装备槽交换（拖拽可选，点击为主）

## 与 v4.5 rack 的关系
- rack 概念升级为 equipment(每槽最多2) + storage(容量制)
- 存档迁移：旧 rack 超出2格的部分自动转入 storage

## 掉落扩充（v9.5）
- 新增掉落类型 weapon：从商城武器池按稀有度加权（白60/绿25/蓝10/紫5）
- 掉落武器 = 全新 WeaponInstance(随机lvl 0~1)；紫级附 affix 词缀属性(v6.x复用)

## UI（v9.3）
- 背包面板重构：左列装备栏(6槽可视化) / 右列背包格(容量上限显示 x/12)
- 点击交互：背包物品点击 → 弹出"装备(交换)/丢弃"；装备栏点击 → 卸下入背包
- 容量升级卡在商城 supply 页
