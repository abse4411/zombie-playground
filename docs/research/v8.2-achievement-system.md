# 调研 · 成就体系设计（v8.2）——已读 INDEX 全部，本篇为成就/解锁设计增量

来源：GameDeveloper(Cogmind成就体系:记录进度+技能里程碑+每级独立成就)、Yu-kai Chou(分级制:20项=10铜+6银+3金+1白金 复活参与曲线)、
Trophy.so(铜银金=同一行为递增阈值10→100→1000)、HeroicLabs(成就解锁奖励:货币/角色/武器/外观)、FreeFire(4级制+专属奖励)。

## 设计原则落地
1. **分级制**：铜→银→金→白金，同一行为递增阈值（击杀10/100/1000/5000）
2. **五类**：战斗(击杀/爆头/连杀)、生存(波次/坚守/无伤)、探索(地图/隐藏)、剧情(章节/Boss/番外)、收集(武器购买/Perk满级/金钱)
3. **成就奖励**：解锁角色/武器/Perk/涂装——成就不再只是徽章
4. **进度可视化**：每条成就显示 当前值/目标值 进度条（存档累计计数器）
5. **解锁弹窗**： toast 改为专属横幅+奖励说明
