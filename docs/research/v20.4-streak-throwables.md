# 调研 · 肉鸽割草贪婪循环/连杀奖励 + 现实手雷引信（v20.4）

来源：Vampire Survivors 贪婪循环设计拆解（The Arcade Artificer）、VS-like 维基与社区金币机制讨论、
Wikipedia M67 手雷（引信 4±1s）、Wikipedia/CAT-UXO RGN 冲击引信手雷（UDZS 双模引信）。

## 一、贪婪循环（Greed Loop）—— 击杀金钱 + 连杀奖励的设计依据

VS-like 的核心上瘾结构：**击杀密度 → 金钱/宝石 → 磁吸拾取 → 更贪的走位 → 更深的险**。
金钱乘数（关卡乘数、Arcana、连杀加成）全部指向同一原则：**奖励玩家待在危险里，而不是苟着**。

→ 本项目落子（v20.4）：
1. **击杀基础金钱大幅下调**（×0.4）：挂机摸奖励显著变少。
2. **连杀系统**补回：3 秒窗口内连续击杀叠连杀数，每杀加成 = 基础 × min(2.0, 连杀数×0.1)，
   即 10 连杀收益翻倍、20 连杀三倍封顶——激进压尸潮的总收入反超旧版，苟着则远低于旧版。
3. **里程碑爆赏**：10/25/50/100 连杀节点额外奖金 + 播报（老虎机式多巴胺节点）。
4. 局内强化新增「连杀狂潮」延长窗口/提高加成，让 build 围绕贪婪循环成型。

## 二、现实手雷引信 → v20.4 投掷物分化

| 型号 | 现实机制 | 数值 | → 本项目 |
|---|---|---|---|
| M67 破片手雷 | 松开保险握片启动延时引信 | 引信 4s ±1s（军规中心值 4s） | 破片手雷 fuse 1.7s → **4s**（反弹/滚地后有充分 bank shot 窗口） |
| RGN 极爆手雷（苏） | UDZS 双模引信：冲击起爆 + 延时备份 | 保险解除需 1~1.8s；冲击即爆；备份 3.2~4.2s | 新投掷物**极爆手雷**：掷出 **1.2s 后解除保险**，之后碰丧尸/墙/地立即爆炸；备份引信 4s；保险期内正常弹跳 |

保险期设计直接照搬 RGN 的实战动机（阿富汗山地：手雷弹回掷弹手位置）——防止贴脸自爆，同时保留"提前量撞爆"的操作上限。

## 三、连杀数值模型（确定稿）

- 窗口 window = 3.0s（局内强化可延长）；断连不清零奖金，只停止叠层。
- 击杀入账 = round(基础赏金 × 0.4 × (1 + min(2.0, 连杀数 × 0.1)))。
- 里程碑：连杀数达到 10/25/50/100 → 额外 +$50/$120/$300/$800（吃 cashMult）+ 播报 + 音效。
